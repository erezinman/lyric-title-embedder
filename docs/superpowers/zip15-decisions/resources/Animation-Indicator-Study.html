Animation indicator — a better idea than stacked strips

The strips treat every channel as a duration bar, so a busy cue stacks 3–4 bars into a few pixels. But karaoke animations have two natures — and mapping each to its own visual form makes the crowding disappear.

Transient fire at a moment

Fade-in/out, pop, slide-in. They fire at a moment but still run for a real duration. → a keyframe dot at the start with a bar to the stop.

Sustained run the whole cue

Color shift, glow, typewriter. They span the cue; shown as a soft underglow line across their real range.

▍ Verdict

Adopt Proposal B. Each animation now carries its real start → stop: transient channels render a keyframe dot at the true start with a bar to the true stop, sustained channels underglow only across their actual range. So you read timing and nature at a glance — yet it's still fixed-height (one segment row + one underglow row, never stacks), so V-zoom and short cues don't crush it, and it stays glanceable on a 30-cue song.

The full tl-anim strips become the detail tier: selecting a cue blooms these into the exact draggable bars you already have. Coincident starts collapse to a single cluster dot with a count. Open question: do you also want the cue's own appear/disappear ticks (distinct from its event window) marked on the lane, or is the block's left/right edge enough?
