Event authoring — naming what SRT can't import

An .srt brings in cue text + line timing (words share their cue's timing). It has no concept of events, names, or sections — so it lands as one flat "Subtitles" group. This panel is the method to author the gaps: group cues into events, name them, set a section. (Style, animation, placement and per-word retiming already have their own editor surfaces — those aren't import gaps.)

▍ Verdict / proposal

Ship an Events panel (lives in the Project rail or the Lanes dock) as the home for the import-gap metadata: inline-rename names, a section <select>, a linger stepper, and grouping actions (＋New · Merge selected · Split at cue). Names also editable inline on the timeline lane header — both write layout[i].label. The event color is its brand — clicking the swatch recolors the group everywhere (its lane + every cue block in the timeline).
